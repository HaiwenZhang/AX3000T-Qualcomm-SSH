# 第三方来源

原始方法模块为 `app/init_router.py`、`app/ota_rce.py`，来自 [ADCDS/xiaomi-ax3000t-cabmeshd-disclosure](https://github.com/ADCDS/xiaomi-ax3000t-cabmeshd-disclosure) 的 `poc/` 目录。

两文件原始 SHA-256 记录在 `app/sources.json`。源代码许可和原作者说明保存在 [许可证](../licenses/cabmeshd-LICENSE.md)、[NOTICE](../licenses/cabmeshd-NOTICE.md)。

Python 由使用者从 [Python 官网](https://www.python.org/downloads/windows/) 自行安装，本目录不分发解释器、动态库或虚拟环境。

SSH 依赖为 [ssh2-python](https://pypi.org/project/ssh2-python/)，由使用者通过 `requirements.txt` 自行安装。本目录不分发该库的二进制文件。所列版本提供 Windows CPython 3.13 x64 wheel，因此 README 推荐此环境。
